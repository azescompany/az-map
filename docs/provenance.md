## Canonical dataset (`data/`)

Generated by extract scripts under `scripts/` (`extract_pilot.py`, `extract_baki_*`,
`extract_sumqayit.py`, city/rayon extractors, …). Each area/place stores
`source_refs` with `source`, `source_id`, and `release`. Hierarchy verification
follows [`Hierarchy.md`](../Hierarchy.md) / [`WORKER.md`](../WORKER.md).

Release tags:

- Overture: `2026-09-23.1`
- OSM extract: `azerbaijan-261020`
- GeoNames: `AZ.txt`

Coverage (national pilot): country + Bakı districts + republic cities +
administrative rayons (including Naxçıvan MR). Invented geometry is forbidden;
conflict children stay out of cascade dropdowns (`parent_status=conflict`).

## Places catalog

`data/places/index.json` lists per-area place files used by demo search
(`loadAllCatalogPlaces`). Landmark taxonomy is Overture-derived; unnamed places
are filtered in the UI only.

## External basemap

OpenFreeMap Liberty (`https://tiles.openfreemap.org/styles/liberty`) is used only
as visual context. Administrative boundaries and place markers are served from
`data/`.
